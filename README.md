# ふたり精算ノート（pairsettle）

2人で立て替えた支出を記録し、「今どちらがどちらへいくら払えば精算完了か」を常に表示する小さな Web ツールです。同居・ルームシェア・パートナーとの割り勘精算を想定しています。

## 使い方

1. トップページで支出を登録します（払った人／金額／内容／分担方法）。
2. 分担方法は「半々」「7:3」「6:4」「3:7」「4:6」「相手が全額」から選べます（割合は「払った人：相手」の負担割合です）。
3. ページ上部に現在の精算結果（例：`Bさん → Aさん へ ¥500`）が常時表示されます。
4. メンバーの名前はページ下部のフォームで変更できます（既定は「Aさん」「Bさん」）。
5. 支出は一覧から削除できます。

データは SQLite に保存されます。DB のパスは環境変数 `PAIRSETTLE_DB` で変更できます。

## ローカル実行

```bash
pip install -r requirements.txt
python app.py
# http://localhost:5000
```

## テスト

```bash
python -m unittest discover -s tests
```

## Render へのデプロイ

`render.yaml` を同梱しています。Render でリポジトリを接続すれば、無料プラン（free）の Web Service としてデプロイできます（buildCommand: `pip install -r requirements.txt` / startCommand: `gunicorn app:app` / healthCheckPath: `/healthz`）。

## 制限事項（正直なところ）

- 対応は **2人専用** です。3人以上の精算には対応していません。
- ログイン機能はありません。公開デプロイする場合は URL を知っている人が誰でも閲覧・編集できます。個人間の利用に留めるか、Render の IP 制限等の併用を検討してください。
- Render 無料プランではファイルシステムが永続化されないため、再デプロイやスリープ復帰時に SQLite のデータが消える場合があります。大事な記録のバックアップには向きません。
- 割合計算は円単位に四捨五入するため、端数で 1 円程度ずれることがあります。
